## Import

### Option A — .apkg (one-click)
Download the latest `.apkg` from **Releases** → open it in Anki. Done.

### Option B — Text import (pipe-delimited)
1. Copy the contents of `anki_import.txt` into a `.txt` file (UTF-8).
2. Anki → **File → Import** → select the file.
3. Set **Field delimiter** to `|`.
4. Map **Field 1 → Front**, **Field 2 → Back**.
5. Click **Import**.
